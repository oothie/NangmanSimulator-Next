# 낭만강호 통합 시뮬레이터

한국판 낭만강호 시뮬레이터 · **v1.3.0**

사이트: https://nangman-sim.pages.dev/

## 기능

- 세수 자동 탐색 및 모의 세수
- 장비 찾기, 보유 장비, 제작·정련·망정·촉련
- 인물 및 계정 기록, 수련·단약
- 무학·기예·비결·장비·상태 백과
- 암시장 (한정 잔편 구매 전략 1~3장 선택, 08시·20시 인게임 목록 확인 시 무료 갱신), 필드·관문 드랍 (4개 출시 관문 원본 RNG 메커니즘 및 특수 보상 조건), 비단/경문/책장 (십방집·새북), 임무

## 개인정보

방문자가 가져온 세이브 파일은 해당 브라우저에서만 처리하고, 원격 서버로 자동 전송하지 않습니다. 불러온 세이브와 자동탐색 결과는 방문자별 브라우저 저장소에 보관하며, 사용자가 세이브 해제를 선택하면 삭제합니다. 장비 찾기에서 직접 저장한 옵션 조건도 해당 브라우저에만 보관합니다.

공개 저장소는 실제 방문자의 세이브, 계정 정보, 개인 시드, 실측 테스트 파일을 포함하지 않도록 관리합니다. 정적 사이트 배포 시에는 `node scripts/build-public-v114.cjs`가 생성하는 `dist-public/`만 사용합니다.

상태·기예 아이콘은 검증된 PNG를 사이트에 직접 보관합니다. 나머지 아이템·장비 아이콘은 원본 확인과 재배포 권한 검토 후 설치합니다.

이 사이트는 비공식 커뮤니티 도구이며 게임 운영사와 무관합니다.
