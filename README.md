# 낭만강호 통합 시뮬레이터 (Next)

배포 사이트: https://nangman-sim.pages.dev/

현재 UI 버전: **v0.6.7**

## 설계 기준
- yy-sim 화면 구조를 참고해 한국어 UI를 자체 구현합니다.
- 장비 계산 엔진은 산부진 APK의 MakeRnd 및 WASM 메커니즘만 사용합니다. Roboking·yy-sim의 장비 계산 엔진은 연결하지 않습니다.
- 세수는 yy-sim 엔진을 한국판 세이브와 대조해 연결합니다.
- 백과는 NangmanGame 한국판 APK 복원 데이터를 사용합니다.
- 항산과 전투 탭은 유지하되 계산 미구현입니다.
- `内息`은 반드시 `내식`이라고 표기합니다.

## 현재 구현된 UI
- 56px 상단 가로 메뉴, 배경 산수화 레이어, 한국어 밝은/어두운 테마
- 왼쪽 캐릭터 목록, 오른쪽 세수 화면 및 세수·치환 시퀀스·경로 탐색 탭
- 장비: 제작/가방/자동/홍무 탭 표시
- 백과: 카테고리 탭 및 검색 자리
- 일일: 귀시/행상/드랍 탭
- 로컬 JSON 세이브 불러오기, 캐릭터 목록

## 중요 제한
- **UI 복원 진행 중**입니다. 전체 yy-sim 기능이나 문구가 이미 완벽 복제·번역된 단계가 아닙니다.
- 한국판 세수 시드·잠금·천장 매핑과 장비 엔진은 미연결이며, 계산 버튼은 비활성화했습니다.
- 원본 yy-sim 배경 이미지 경로는 외부 참조 중입니다. 이미지가 차단되면 저장소의 대체 배경으로 표시됩니다. 재사용 권한과 안정적인 자체 호스팅 확인이 필요합니다.
- Cloudflare Pages 실제 배포 완료 여부는 GitHub 커밋과 별도입니다.

기존 `oothie/NangmanSimulator` 저장소는 수정하지 않습니다.

## 백과 데이터 정책 (v0.5.8)
- 백과의 전체 분류, 항목 목록, 상세 데이터 스키마는 **yy-sim**을 기준으로 합니다. 한국판 인덱스로 원본 목록을 대체하지 않습니다.
- NangmanGame 한국판 추출물은 동일 ID의 이름/설명 번역 대응표로만 사용합니다. 기존 361건은 제한적인 번역 대조 데이터입니다.
- 아직 번역 대조가 없는 원본 항목은 **번역 대기**로 표시하며 임의로 한국판 이름을 만들어 넣지 않습니다.
- 원본 yy-sim 백과 JavaScript는 현재 원본 서버 경로에 의존하므로 외부 호스팅의 가용성과 재배포 권한을 추가 검증해야 합니다.

## v0.6.2 산부진 장비 화면 복구
- **통합 사이트 장비 메뉴는 더 이상 iframe을 사용하지 않습니다.** 빠른 조회(기본)·자동·수동·주황 장비 순서·검왕각 수동·검왕각 자동이 별도 **동일 사이트 직접 경로**에서 산부진 APK 본래 HTML/CSS/JavaScript를 실행합니다.
- 산부진 원본 기능을 분리 유지하는 직접 라우팅 방식이며, 아직 단일 SPA 내부에서 개별 엔진 함수만 이식한 구조는 아닙니다.
- 검왕각용 원본 2개 HTML 파일 및 원본 스타일/공통 스크립트를 복구하고, 제작 Worker 경로를 자체 호스팅 URL로 수정했습니다.
- 브라우저 탭 이동 시 JSON 세이브는 용량이 작으면 sessionStorage를 통해 전달되며, 새 화면에서 '통합 세이브 적용'을 누를 수 있습니다. 용량이 큰 세이브는 산부진 자체 가져오기 기능을 사용합니다.
- 독립 Node VM 시험에서 산부진 WASM 로딩과 장비 데이터 테이블 초기화가 모두 성공했습니다.
- **전체 UI/E2E 검증은 아직 완료되지 않았습니다:** 로컬 Chromium이 접근을 차단했고, 실제 자동 탐색·빠른 조회·한국판 세이브를 이용한 계산 결과는 실브라우저 검증이 필요합니다. 본 단계를 '완벽 구현'으로 표시하지 않습니다.
- 상세 체크포인트: `checkpoints/2026-11-21-v0.6.2-native-equipment.md`.

## v0.6.5: 빠른 조회 상세 보기·세이브 알림 제거·장비 옵션 표시 개선 (2026-11-21)

- **검증 현황**: 수정 JS 구문 파싱 및 포맷터 단위 테스트 통과. 실제 한국판 세이브로 클릭 상세/소모량 정합성 E2E 검증은 미완료.

- **한국판 용어·동적 문장**: 세수 충돌맥·첫 자맥·치환 맥 순서, 경로 검색·비용, 장비 제작·정련·망정·검왕각 결과 문장 다수 원본 JS 템플릿에서 직접 번역. 한국어 번역 사전에도 동적 단위와 상태·오류 문장을 추가.
- **한글 문자 코드 처리**: `&#xAD00;` 등 HTML 숫자 엔터티가 이중 이스케이프되어 출력되는 경우를 번역 단계에서 복원. `内息`=내식, `穿甲`=관통, `免伤`=피해면역 등 기준 유지.
- **장비 데이터 검증**: 장비명 391/391, 도면명 166/166, 장인명/지역 56/56, 추가 재료 22/22, 재료 이름 34/34, 옵션명 39/39, 종류 12/12, 색상 6/6을 정적 번역 함수로 확인했을 때 한자 잔여 0건. 원본 패션 설명 문자열 약 790개는 현재 장비 계산기에서 참조하지 않는 데이터이며 이 검사 범위에 포함하지 않음.
- **코드 문자열 검사**: 세수·장비 주요 화면의 JavaScript 표시 문자열에서 번역 적용 이후 중국어 잔여 후보를 제거. 이 검사는 추출된 정적/템플릿 문자열 기준이며 한국판 실세이브 E2E 및 모든 팝업·백과사전 포함 중국어 0건을 보증하지 않음. 기존 `NangmanTranslationAudit.scan()`으로 실제 표시 DOM을 별도 확인할 수 있음.
- **범위**: 시뮬레이터 계산 로직과 시드 상태·세이브 전달·빠른 조회 동작은 변경하지 않음.
