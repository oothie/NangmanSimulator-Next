## v0.10.31 — 한국판 세이브 기반 녹·파맥 원본 WASM 혼합 목표 실험 탐색 연결
- 통합 시뮬레이터 세수 자동탐색에서 **녹맥·파맥·자맥을 최대 4개 직접 선택하고 계산 버튼으로 원본 `wasmSearchWashRoutes`에 전달**할 수 있도록 기존 자맥 전용 제약을 제거했습니다. 캐릭터 세이브·원본 WASM 상태를 그대로 사용합니다. 별도의 자체 순차 세수·잠금/빔 탐색을 만들지 않았습니다.
- `vendor/yysim/engine-host.html`에서 원본 재능 `TALENT_DATA` 등급 2/3/4와 실제 `YYWashTargetCatalog` 등록 ID만 허용하고, 원본 반환 경로의 **`final_slots`에 요청한 모든 재능이 동시 존재하는지** 검증하는 `nativeDiagnostics`를 반환합니다. 원본 WASM 바이트는 변경하지 않았습니다.
- `engine/yysim-auto-progressive.js`는 원본이 **중간 획득 또는 일부 재능만 포함한 경로를 반환했을 때 결과에서 제외**하고, 검색된 후보 수와 미완성 경로 수를 별도 표시합니다. 확인된 완성 경로가 없으면 **최저 세수단은 미확정(`null`)**으로 처리합니다. 한 번의 원본 WASM 호출과 사용자 탐색 범위는 그대로 유지합니다.
- 세수탭에는 녹·파맥 검색을 **`원본 WASM 실험 탐색`**이라고 명확히 표시하고, 미완성 경로 제외 이유를 알려줍니다. 사용자가 제공한 3자맥 완성 / 3자맥+1녹맥 불완전 사례처럼 혼합 목표가 완성되지 않으면 성공으로 표시하지 않습니다.
- `tests/yysim-native-mixed-dispatch-smoke.cjs` 및 `tests/yysim-auto-progressive-smoke.cjs`에 원본 WASM 호출 계약, 녹·파맥 대상 전달, 미완성 최종 슬롯 검출, 실제 최종 목표 충족 시만 성공 판정, 가짜 최저 비용 방지 검사를 추가했습니다. 실제 저장소 호스트 코드와 경로 어댑터를 JS 격리 실행한 검사에서 **불완전 혼합 목표가 완성 0개로 처리되는 것**을 확인했습니다.
- **중요 미완료:** 이는 WASM에 녹·파맥 목표를 전달하여 실제 반환값을 검증하는 **실험적 확장**입니다. 내부 `next_purple` 후보 생성까지 등급 2/3으로 확장하거나 **혼합 최종 경로의 전역 최소 세수단을 찾는 원본 WASM 알고리즘 수정**은 아직 하지 않았습니다. 원본이 반환하는 불완전 결과를 최소 경로로 위조하지 않습니다. GitHub Actions 실측 및 브라우저 배포 검증도 미확인입니다.

## v0.10.26 — 원본 세수 상태 비교 오류 수정 및 혼합 목표 WASM 직접 실행 검증
- **실제 상태 판정 수정:** 원본 WASM의 `global_vars` 등 객체는 Rust/JSON 직렬화에서 속성 순서만 달라질 수 있습니다. 기존 `JSON.stringify(before)!==JSON.stringify(after)`는 내용이 같아도 오류·불필요한 복원을 일으킬 위험이 있으므로, `engine/yysim-native-search-guard.js`에 **중첩 객체의 키만 정렬하는 구조적 비교**를 구현했습니다. 재능 슬롯 배열 순서·시드·잠금 여부 등 값 차이는 그대로 감지합니다. 특수 키 `__proto__`도 누락되지 않도록 null-prototype 객체로 정규화합니다.
- 이 비교를 실제 `engine-host.html`의 **원본 자동탐색 상태 보호·재능 충돌 조회·연동 치환 검색**과 독립 WASM Worker/브라우저 검증에 연결했습니다. 연동 치환 상태 복원 실패는 성공으로 표시하지 않습니다. WASM 원본 바이너리와 자맥 검색 알고리즘은 **변경하지 않았습니다**.
- `tests/yysim-native-search-guard-smoke.cjs`에 객체 키 순서 변경 허용, 실제 시드/슬롯 순서 변경 감지, 특수 JSON 키 보존, WASM 오류 복원 검사를 보강했습니다. 저장소 최신 소스를 직접 실행한 구조적 비교·읽기전용 검사와 관련 JS 파일 구문 검사는 통과했습니다.
- **원본 WASM 실측용 Node.js 테스트 추가:** `tests/yysim-native-headless-grade.cjs`가 브라우저 없이 `wasm_data.js`와 `core_glue.js`를 그대로 초기화하여 자맥 단독·녹맥 단독·파맥 단독·혼합 목표를 실행하고, **자맥 3개 대 자맥 3개+녹맥 1개**의 동일 시드/범위 결과 및 경과 시간을 비교합니다. 같은 상태에서 자맥 원본 결과의 재현성과 상태 보존도 검사하며 CI `yy-wash-native-regression.yml`에 연결했습니다.
- **중요:** 새 Node.js 테스트는 GitHub 저장소에 추가된 실행 코드입니다. 실제 **원본 WASM 실측 로그 및 GitHub Actions 통과 결과는 아직 확보하지 못했습니다.** 따라서 녹맥·파맥 최종 최소 경로, 품질 판정 분기 및 Worker 전환은 여전히 미완료입니다. UI에 미검증된 탐색 결과를 표시하지 않습니다.

- 현재 코드 문법 및 연결은 검증 대상이나 실제 브라우저 기능 테스트·배포 상태 확인 전에는 완전 배포 승인으로 보지 않습니다.
