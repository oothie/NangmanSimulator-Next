# 낭만강호 통합 시뮬레이터

한국판 낭만강호 세이브를 읽어 캐릭터·세수·장비·일일·드랍·임무 및 백과 데이터를 조회하는 브라우저 기반 독립 시뮬레이터입니다.

**공개 배포 버전: v1.1.5**

사이트: https://nangman-sim.pages.dev/

## 제공 기능

- **세수:** yy-sim 원본 WASM 기반 재능·잠금·치환 및 자동 경로 조회
- **장비:** 기존 v3.50 장비 계산 엔진을 활용한 상세 조회 및 정련·망정
- **인물·계정:** 세이브의 동료, 능력치, 수련, 단약, 강호 기록과 지도자원
- **백과:** 한국판 데이터 기반 무학·기예·비결·장비·상태 등 명칭과 설명
- **일일:** 암시장 갱신과 구매 조건, 일일 기록 및 예측
- **드랍:** 필드·관문 별도 조회. 원본 RNG 복원이 완료되지 않은 결과는 가설/미검증으로 표시
- **임무:** 한국판 임무 자료와 세이브 진행도 연동

## 배포 규칙과 개인정보

- **사용자 세이브 예시는 배포하지 않습니다.** 배포 패키지는 계산용 정적 파일과 번역 자료만 포함합니다.
- 세이브 JSON은 각 방문자의 브라우저 안에서만 읽고 계산합니다. 자동 서버 업로드 기능은 없습니다.
- 예시 세이브는 배포 파일에 포함되지 않습니다. 각 방문자가 직접 불러온 파일은 해당 브라우저에만 저장되며 상단 **해제** 버튼으로 지울 수 있습니다. 기존 방문자의 개인 저장 세이브를 임의 삭제하지 않습니다.
- 배포 전 **`node scripts/build-public-v114.cjs`** 를 실행하고, 출력 폴더 **`dist-public/`** 만 정적 호스팅에 배포합니다. GitHub 저장소 전체를 웹 루트로 배포하지 마세요.
- `tests/`, `docs/`, `checkpoints/`, `release-reports/`와 실측 예시 파일은 공개 정적 번들에 포함되지 않습니다.
- PNG 게임 아이콘은 검증된 원본 자산이 제공될 때만 표시합니다. 설치되지 않은 아이콘은 대체 표시를 사용하며 존재하지 않는 경로를 요청하지 않습니다.
- 원본 게임·외부 라이브러리의 저작권 및 재배포 허용 범위는 별도로 확인해야 합니다.

## 개발용 검증

```bash
node scripts/build-public-v114.cjs
node scripts/release-audit-v114.cjs
node scripts/release-test-matrix-v114.cjs
```

Chromium 전체 탭 및 합성 세이브 검사: `node tests/public-browser-v114.cjs` (Playwright 설치 필요).

각 실행의 결과는 `release-reports/`에 기록됩니다. 이 폴더는 공개 배포 파일에서 제외됩니다.

## 검증 범위의 한계

세수 자동탐색은 실제 yy-sim WASM 경로를 재현하여 후보를 제시하지만 **무제한 전역 최소 소모량을 보장하지 않습니다.** 관문과 필드의 장비 드랍 ID·색상 및 옵션 난수는 일부 구간의 원본 복원·실측 대조가 진행 중이므로 예측 결과를 반드시 실게임 사실로 간주해서는 안 됩니다.

이 프로젝트는 비공식 커뮤니티 도구이며 게임 운영사와 무관합니다.
