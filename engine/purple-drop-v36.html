60014 관문 스크립트에서 확인한 보스별 장비 풀과 실제 추첨 가중치를 사용합니다. 연왕부 3개 보스·벽유교 3개 보스가 대상이며, 벽유교 3명은 하나의 seed_byj를 순서대로 공유합니다. 원본 특수보상 분기의 시드 소비가 확정되지 않은 구간은 조건부 시나리오로 계산합니다.

최신 세이브를 위쪽에서 불러오세요.

판정 주의: 보스별 지급 배열과 품질 가중치는 원본 추출값입니다. 하지만 특수보상 분기(조건·누적 횟수·키 상태)가 RNG를 몇 번 소비했는지, 다음 관문 입장 사이 상태 변화가 있는지는 아직 완전 복원되지 않았습니다. 표시한 회차는 고정한 추가 호출 수에서의 조건부 후보이며 확정 드랍이 아닙니다. 미래 자색 장비의 최초 옵션은 미복원입니다.

당일 자색 장비 계획 · 동일 ID 획득 순번별 Eds / 정련

그날 첫 사냥·관문 진행 전 최신 세이브를 위에서 불러온 뒤, 현재 사이트에서 이미 검증된 드랍 예측을 입력하세요. 자색 등장 시점은 사이트 예측을 신뢰하고 이 페이지에서는 같은 장비 ID의 누적 획득 건수를 세어 시드를 계산합니다.

한 줄에 한 번의 실제 장비 획득을 입력합니다. 구분자는 탭 · 쉼표 · | 이며 양식: 사냥터/관문, 회차, 보스, 장비ID(또는 이름), 등급. 같은 ID의 백색·녹색·청색도 한 번씩 계산합니다. 미드랍이나 재료는 입력하지 않습니다. 한 행의 수량이 여러 개면 행을 그 수량만큼 반복합니다.

그날 시작 전 세이브를 위쪽에서 선택하세요. 세이브는 브라우저 메모리에서만 처리됩니다.

복원 범위: Rnds.Eds의 동일 ID 순차 갱신과 MJSeed/CZSeed 및 기존 정련·망정 상세. 최초 드랍 장비의 옵션 1·2·3 생성은 원본 생성 함수 검증 전이므로 미확정으로 표기합니다. 이 계산은 드랍 장소나 색깔만으로 다른 장비 ID의 Eds를 소비시키지 않습니다. 세이브 시점 이후 이미 획득한 같은 ID 장비가 빠지면 해당 획득 순번 이후 예측 전체가 달라집니다.
