# v0.6.3 장비 통합 및 한국어화 체크포인트 — 2026-11-21

## 변경 완료
- 기준본 `index.html` v0.6.2 → v0.6.3; 장비 클릭 시 `location.assign`으로 산부진 사이트로 나가던 코드를 제거.
- 메인 사이트 장비 하위 메뉴로 빠른 조회/자동 탐색/수동 제작·정련/주황 장비 순서/검왕각 수동/자동 6개 기능 통일.
- 장비 계산은 산부진 APK 원본 JS/WASM만 사용, 계산 전역 충돌 방지를 위한 same-origin iframe은 사용자 UI 뒤에 격리하며 중복 산부진 자체 상단 내비게이션은 숨김. **완전한 DOM 합체는 아님.**
- 최초 접근 후 하위 메뉴 전환 시 iframe을 DOM에서 제거하지 않고 유지. 메인 사이트 `save` 단일 객체를 `nangman-equip-save` 메시지로 전송, 새 세이브 로드 시 열린 모든 장비 엔진에 자동 전파.
- 각 산부진 원본 HTML 6곳: 자체 `native-equipment-navigation.js` 로더 제거, `.feature-heading/.feature-mode-nav` 숨김, 배경 투명화, `YYJHI18n` 한국어 모드 강제, 엔진 준비 및 세이브 적용 확인 응답 브리지 추가.
- `shared/i18n.js`에 이번 조사에서 누락 확인한 장비·검왕각 중국어 고정문구 33개를 한국어 추가.
- 백과/산수화/세수/드랍/항산·전투 탭은 기존 상태 보존.

## 검증
- `index.html` JavaScript 구문 검사 통과.
- 산부진 원본 6개 HTML 내부 스크립트 구문 검사 통과.
- 같은 출처 브리지와 6개 원본 탭 메뉴가 소스에 존재함을 확인.
- **브라우저에서 실제 세이브 로드와 수동·자동 결과 계산 성공은 아직 확인되지 않음.** 기능 완료로 주장하지 말 것.

## 알려진 제한
- `sessionStorage` 임시 저장은 약 3.8MB 이하; 같은 페이지에서는 메모리의 원본 JSON을 그대로 전달하므로 탭 전환 시 추가 업로드 불필요.
- 다른 브라우저 탭/새로고침 시 큰 세이브는 다시 불러와야 할 수 있음.
- 다수의 원본 JS 고정 문구는 10,000여 항목 번역 사전으로 처리. 이번에 추가한 33개 외에 동적 메시지와 원본 게임 ID 이름은 추가 전수 검증 필요.
- 원본 화면의 독립 WASM 범위를 유지하기 위한 iframe 기반 설계. 장비 화면의 원본 입력·결과 DOM을 완전히 재작성한 상태가 아니므로 추후 장기적으로 각 계산 API를 하나의 SPA 상태 모델로 점진 이관 가능.
