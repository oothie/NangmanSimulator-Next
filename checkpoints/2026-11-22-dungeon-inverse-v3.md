## 고정 실측
- 벽유교: 독선생 4609 청색, 미 5009 백색, 불로선인 4009 백색.
- 창옥: 무준신 일반 장비 미드랍·몰우전(3523) 1개, 이장 4009 녹색, 장정 미드랍.
- 유씨별원: 윤무 미드랍, 고리 5209 녹색, 이뢰운 4209 녹색.
- 관문 실행 순서: 벽유교 → 창옥 → 유씨별원, 각 1회.

## v2 대비 변경
- v2 source/native 모델이 실제 측정과 모두 불일치하므로 두 결과 모두 미검증으로 유지.
- 신규 `vendor/sanbujin/drops/dungeon-v3-inverse.js`는 두 모델의 장비 ID/등급 적중률을 별도로 기록하고 동일 RNG 키에 대한 시작/종료 시드 역추적을 수행.
- 알려진 추첨 범위와 후보 미복원 호출의 삽입으로 최소 누락 호출 수/가능한 호출 범위/전후 시드 경로를 BFS로 탐색.
- 보스 보상 측정값을 예측값에 덮어쓰거나 특정 시드 결과를 강제하지 않는다.
- `SBJDungeonInverse.rebuild(before,after,plan,catalog,measured,options)`가 각 모델의 측정 비교/전후 Sds 변화 후보/검증 불가 상태를 함께 반환.
- 한계: 후보 범위 집합에 진짜 누락 호출 범위가 없으면 해를 못 찾음. 시드 변화 후보만으로 원본 실행 경로가 완성되었다고 판정하지 않음.
- 기존 두 엔진 및 공용 Eds, 실사용 예측 데이터 유지, 세이브는 불변. 공개 저장소에 실제 개인 시드 업로드하지 않음.

## 검증
- 신규 단위 테스트 `tests/dungeon-v3-inverse-smoke.cjs` (기지 호출만, 중간 미지 호출, 결측 시작 시드, 두 결과 불일치 시 원본 보존).
- 테스트 파일은 추가했지만 이번 변경에서 GitHub Actions 정상 완료는 확인되지 않음. Character regression workflow의 기존 Diling v29 독립 비교 단계가 실패해 전체 워크플로는 실패로 표시됨.
