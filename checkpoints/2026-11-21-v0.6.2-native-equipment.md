## 확인된 문제와 수정
1. 장비를 기존 yy-sim 카드 + iframe으로 표시해 원본 산부진 빠른 조회·자동·주황 순서 화면이 보이지 않음 → 장비 메뉴 자체를 산부진 직접 라우트로 변경.
2. 검왕각에 잘못된 `equip/index.html?tab=jianwang` 링크와 누락된 전용 원본 페이지가 있어 앱 자체를 다시 표시 → APK에서 실제 `jianwang-manual/index.html`, `jianwang-auto/index.html`를 추출해 GitHub 등록.
3. 기존 quick·auto·manual·orange는 각 APK 페이지를 GitHub 내 실제 직접 경로로 유지하고, 네이티브 공용 사이트 메뉴 `engine/native-equipment-navigation.js` 삽입.
4. APK UI 스타일 `shared/app/appearance.css`, `shell/shell.css`, `shared/app/theme.css`, `shared/app/workbench.css`, `shared/app/feature-page.css` 복구.
5. 검왕각 자동의 부가 종속 코드 `hengshan/{core,app}.js`, `shared/hengshan_{talent,shop}_data.js`, `hengshan/hengshan.css` 복구.
6. 장비 미리보기 worker와 공통 시뮬 스타일의 `/suanbujin/` 하드코딩을 `/vendor/sanbujin/`으로 수정.
7. 메인 사이트 ↔ 산부진 장비 페이지 사이 세이브를 세션 내 `sessionStorage`로 전달하는 버튼 구현. 3.8MB 넘는 세이브는 장비 화면에서 원본 가져오기 사용.
8. 사용하지 않는 외부 URL 연결 파일 `engine/sanbujin-equipment.js`, `engine/wash.js` 제거.

## 검증 근거
- 동일한 산부진 APK에서 선별 추출한 154개 JS 파일에 대해 `node --check` 구문 검사: **0 오류**.
- 산부진 핵심 데이터/wasm_data/sequence_rules/core_glue Node VM 독립 시험: `initWasm() === true`, `wasmMakeInitTables(EQUIP_DATA) === true`.
- Chromium 직접 브라우저 테스트는 `ERR_BLOCKED_BY_ADMINISTRATOR`로 환경상 불가. **빠른 조회·자동 최적화·검왕각 실제 버튼 실행/한국판 세이브 예측의 엔드투엔드 검증은 미완료.**
- Cloudflare Pages 최신 커밋 반영은 검증되지 않음.
- 산부진의 원본 기능을 완전히 리팩터링해 단일 DOM에 넣은 방식은 아님. `iframe` 없이 동일 출처 직접 페이지를 장비 탭 라우트로 사용해 기존 계산 코드 충돌을 방지.
