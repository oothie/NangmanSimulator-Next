# v0.7.7 한국어화 정적 점검 (2026-11-21)

## 작업 기준
- v0.7.6에서 진행, 기존 장비 계산·시드·드랍 난수 함수 변경 금지
- 한국판 V6.20 명칭/설명과 기존 번역 사전 우선 사용
- 획득처 추가 없음, 미출시 항산 관련 고유명사는 무단 확정 번역 금지

## 변경 범위
- `vendor/sanbujin/shared/simulator.js`: 세수, 첫 자맥·치환, 되돌리기, 목표 경로, 장비 자동 탐색, 검왕각 자동 탐색의 인용 문자열 401종(199+147+55)과 HTML 출력 패턴 약 60종을 한국어로 직접 변경. 후속 오류 및 출력 메시지 보정 추가
- `vendor/sanbujin/drops/index.html`: 필드/관문/보물지도 화면의 텍스트, 버튼, 안내, 규칙 한글화. 중국어 한자 0건(이 파일 정적 HTML 기준)
- `wild.js`, `dungeon.js`, `treasure.js`: 상태, 결과, 경고 안내 전수 한글화, 정적 인용 중국어 후보 0건
- `wild-core.js`, `dungeon-core.js`, `treasure-core.js`: 오류 및 사용자 출력 명칭 번역. treasure-core의 원래 지역 식별 명칭은 내부 순서와 비교를 위해 유지
- `shared/equip_auto_strong_preview.js`: 은냥 단위 번역
- `dungeon.js`, `wild.js`: 원본 데이터 ID/조회키를 보존하면서 장비 `koName` 및 기존 한국어 사전을 출력 우선순위로 적용

## 검증
- 수정된 주요 JS 10개에 대한 V8 JavaScript 구문 검사 통과
- 화면 정적 검사: 드랍 index 0건, wild/dungeon/treasure UI 스크립트 0건
- 남은 simulator.js/equip.js의 중국어 후보는 주로 원본 테이블 조회키, 장비·재료·지역 식별자이며 한국어 렌더링 사전에서 대응을 확인해야 함
- 드랍 카탈로그 원본 이름 약 150종 대조: 번역 사전에 없는 짧은 NPC명 3종(迷, 茧, 风). 공식 한국판 표기 불명: 이름을 임의로 확정하지 않음
- 실제 브라우저, 한국판 실세이브로 모든 탭/팝업을 연속 구동한 E2E 검증은 여전히 미완료. 원본 계산 결과가 100% 동일하다는 별도 검증은 하지 않음
- 원본 중국어 로직 식별자(接受/取消, 원본 역할 tag/seedKind, 지역·도면 탐색 키), 추첨·시드 계산/상수는 유지하거나 실수로 바뀐 경우 원복
