# v0.7.14 캐릭터·백과 1차 패치 (2026-11-21)

기준: main v0.7.13 / index.html. 작업 저장소: oothie/NangmanSimulator-Next.

## 변경
- 백과 카테고리에서 비급(secret) 탐색 탭을 삭제하고, secret 아이템이 다른 카테고리로 섞이지 않도록 목록에서도 제외.
- 생활기술 분류의 표시명을 '생활기술-기예'로 변경. 기존 craft ID, 기예 42개·비기 111개 번역 사전과 비기(arts) 분류 유지.
- 기예·비기 이미지: 원본 목록에서 icon / pic / img / image / iconId / icon_id에 있는 정수형 이미지 ID를 우선 사용하며, 미확인 이미지는 아이템 기본 대체 이미지로 안전 처리. 한국판 이미지 실물 일치 전수 검증은 미완료.
- 캐릭터: 기존 개요·육성·무학/재능은 보존하고 '착용 장비', '경맥·기록' 세이브 원본 조회 탭을 추가. 저장된 키에서 존재하는 컬렉션만 표시하고 전투 최종값은 추정하지 않음.
- index.html의 브라우저 title·버전 문자열을 v0.7.14로 갱신.

## 검증/한계
- 정적 inline script 파싱: 비-module script의 구문 오류 없음. module script는 import 때문에 일반 함수 파서로 검증할 수 없음.
- 현재 패치는 산부진의 전체 캐릭터 계산 엔진 통합이 아닌 원본 세이브 컬렉션 조회의 1차 연결. 산부진 APK role-status 로직과 실제 한국판 save.json의 계산값 대조는 미완료.
- 아이콘은 ID 기반 URL 연결을 보강했지만 전체 한국판 APK 이미지 대응 및 실제 HTTP 200/시각 일치 검증은 미완료.
- Cloudflare 실브라우저 배포 및 E2E 시험 미검증.

## 후속
산부진 원본 role-status 소스/데이터 추출 → 최종 스탯·전투력 계산 규칙/착용 효과 비교 → 한국판 실제 세이브 검증. 기예·비기 아이콘은 원본 6.20 아이콘 매핑과 병합해 PNG 주소별 일치 검증.
