# 낭만강호 통합 시뮬레이터 v0.7.12 번역 체크포인트
기준: v0.7.11 → v0.7.12 · 2026-11-21 (KST)

## 변경 목표
한국판 용어 우선, 실행 중 생성되는 세수·장비·검왕각·즐겨찾기·세이브 복호화 메시지의 중국어 출력 감소. 계산·난수·원본 판정값 보존.

## 실제 파일 수정
- `shared/simulator.js`: 한국어 장비 도면·재료 그룹·목표 선택 검색 및 UI 결과, 세수 재능명/충돌 안내, 검왕각 재료·경로/망정 설명 한국어 출력. 제작 순서 UI 필터 '일반/행운/천장'이 원본 `普通/幸运/保底`·영문 분류와 불일치하던 문제를 화면 전용 정규화로 수정. 내부 `candidate.seedKind` 유지.
- `shared/equip_auto_optimizer.js`: 정련 조합, 경로 재현, 재료 소모, 입력 오류 등 31종 한국어화. 내부 계산과 객체 이름은 원본 유지.
- `equip/equip.js`: 주능력치 강기/내기, 백련석/녹련석/남련석/자련석 공식 사전 적용.
- `shared/core_glue.js`: WASM 및 제작 상태 오류 11종 한국어화.
- `shared/wash_route_engine.js`: 세수/치환 오류 10종 한국어화.
- `shared/wash_search_manager.js`: 백그라운드 탐색/검증 메시지 21종 한국어화.
- `shared/sequence_rules.js`: 버전/순서 검증 오류 4종 한국어화.
- `shared/archive_state.js`: 세이브 상태/교체/초기화 경고 등 13종 한국어화.
- `shared/international_wash.js`: 충돌 상태·실패 안내 4종 한국어화.
- `shared/fav_store.js`, `shared/equip_favorites.js`: 즐겨찾기 백업, 서버, 장비 CSV 메타데이터와 오류 한국어화.
- `shared/cloud_items.js`: 로그인·등록·저장 카드·망정/정련 팝업/구 버전 HTML 복원 메시지 한국어화. 저장된 카드 텍스트/접근성 이름만 번역하고 원본 데이터는 유지.
- `shared/save_decrypt.js`: 복호화·버전·파일명 안내 및 오류 63개 패턴 한국어화. 원본 채널 및 정규식은 유지하고, 지원 채널 안내 목록에만 표시용 한국어 맵을 추가.
- `shared/i18n.js`: `lang=ko` HTML은 예전 중국어 사용자 환경설정·영문 브라우저보다 한국어를 우선해 시작하도록 설정.
