# 출시 4관문 장비 우선순위 감사 — 2026-11-24

**최종 목표는 일반 드랍 장비 ID·한국판 이름·색상의 정확한 미래 예측.** 유일 장비·잔편·특수재료는 일반 장비 당첨이나 후속 난수 시드에 영향을 미칠 때만 드랍 엔진의 필수 의존성으로 취급한다. 문향교·무신전·벽유교 본단은 미출시 동결을 유지한다.

## 두 보유 세이브에 대한 실증된 민감도 (독립 미획득 세이브가 아님)

서로 다른 기존 1123 입장 전/1124 저장 상태에서 동일한 `Rnds.Sds` 난수 시드를 보존한 채 `get_*` 지급 카운터와 `num_*` 재료 누적값을 개별적으로 0으로 만든 **가정적 반사실 재생**이다. 과거 획득 이력·진입 순서는 복원하지 않는다.

| 관문 | `get_*` 지급 제한만 0 | `num_*` 재료 누적값만 0 | 다음 단계 |
|---|---|---|---|
| 유씨별원 | 양쪽 상태 모두 장비/시드 불변 | 1124: 장비 1~3회 전부 변화, 난수 시드 변화. 1123: 2·3회 장비 변화 | **최우선**: 재료 가중치, `GetP(8915)` 조건, 3회 연속 시드 전달 완성 |
| 창옥 | 양쪽 상태 모두 장비/시드 불변 | 상태에 따라 장비 또는 다음 시드 변화 | **다음**: 재료 누적 변수의 실제 재생 규칙 연결 |
| 연왕부 | 양쪽 상태 모두 장비/시드 불변 | 상태에 따라 현재 장비 또는 다음 시드 변화 | **다음**: 2회 연속 상태 전달과 재료 판정 통합 |
| 벽유교 | 현재 보스 구간 장비/시드 불변 | 현재 보스 구간 장비/시드 불변 | **검증 보류**: 전체 입장·구출 실행 경로의 별도 난수 소비가 일반 장비에 영향 주는지 검증 전에는 독립이라 단정 금지 |

**중요:** 연왕부·창옥도 특수 **재료 누적값**이 일반 장비/다음 시드에 영향을 주므로, 유씨별원만 특수 의존성을 가진다고 단정하면 안 된다. 그러나 구출 재료의 *당첨 아이템* 자체가 일반 장비에 영향을 주지 않는 한 `JHRandom`의 내부까지 복원할 필요는 없다.

### 유씨별원 1124 시작 시드 3회 연속 연구 재생

| 변경 조건 | 1회차 일반 장비 | 2회차 일반 장비 | 3회차 일반 장비 |
|---|---|---|---|
| `get_*`만 0 | 불변 | 불변 | 불변 |
| `num_*`만 0 | 달라짐 | 달라짐 | 달라짐 |
| 숫자 변수 `GetP(8915)`만 1로 변경 | 장비 불변, 시드/호출 횟수 달라짐 | 달라짐 | 달라짐 |

마지막 행은 **한 회차 장비가 같다고 무해한 특수 조건이 아님**을 입증한다. 첫 회차에 시드가 바뀌면 후속 드랍이 달라진다. 1123 시작 상태에서는 `8915`만 바꿔도 첫 회차부터 장비가 달라진다.

## 구현 및 검증

- `gear_first_dependency_audit.py`: 4관문 × 6가지 상태 비교를 **장비/시드 의존성만** 요약. 민감하지 않은 단순 지급 제한 카운터는 장비 계산 필수 경로에서 제외.
- `liu_gear_sequence_sensitivity.py`: 동일 시작 세이브에서 원본 기반 유씨별원 세 번 연속 클리어를 재생해, 각 단계 장비/시드/호출 수 변화만 보고. **개인 실제 시드는 출력하지 않는다.**
- `liu_gear_sensitivity_1123_public.json`, `liu_gear_sensitivity_1124_public.json`: 민감도 판정만 포함한 비식별 결과.
- `test_gear_first_dependency_audit.py`와 `test_liu_gear_sequence_sensitivity.py`: 각각 6개, 5개 검증 포함. 전체 기존 출시 관문 테스트 **86/86 통과**.

## 남은 복원 목표

1. 유씨별원 숫자 `GetP(8915)` 및 재료 누적 가중치가 매 회차 정확히 갱신되는 실제 RNG 소비 경로, 일반 장비 ID/색상까지 연결. 더 많은 미획득 가상 이력을 보정값 없이 평가.
2. 창옥/연왕부의 재료 누적값 변화를 두 번 이상 연속 클리어에 정확히 반영.
3. 벽유교 구출 이벤트는 **일반 장비 난수와 시드 공유/호출 수 변경이 증명될 때까지 별도 보존하고 개발 중지**.
4. 새 실게임 진입 전·후 저장본으로 원본 미래 장비 드랍을 독립 검증.

> 이 문서의 수치는 현재 보존된 1123/1124 상태에서 도출한 **조건부 예측 모델의 민감도 검증**이지, 실제 미획득 계정의 새로운 클리어 실측은 아니다. V82·공개 사이트·미출시 모드 미변경.
