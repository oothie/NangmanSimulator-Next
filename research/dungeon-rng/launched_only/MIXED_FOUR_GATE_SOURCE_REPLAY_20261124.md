# 출시된 4관문 순서 지정 일반 장비 RNG 재생 — 2026-11-24

## 적용 범위

한국 서버 출시: 연왕부, 창옥, 벽유교, 유씨별원. 미출시 문향교·무신전·벽유교 본단의 재생기, 공개 사이트/버전, 원본 V82 드랍 엔진은 변경하지 않음.

기존 개별 관문 재생은 관문별 계산을 모두 *같은 최초 세이브*로 시작했으며, 실제로 여러 관문을 순차 클리어하는 상태 전달에는 제한이 있었다. `mixed_gate_schedule.py`는 지정한 순서에 따라 동일 mutable state를 전달하는 출시 4관문 원본 기반 재생기다.

- 연왕부: `33381_1.lua`, NPC 전용 4개 시드, RNG와 보상 누적/승리 횟수, 슬롯 및 색상 상태 반영.
- 창옥: `40389_1.lua`, NPC 전용 3개 시드, 재료/누적 조건 및 후속 상태 반영.
- 벽유교: `35227_1.lua`, 분기 37 판정과 전용 시드, 승리 횟수/보스 지급 상태 반영. 분기 Step이 이후 클리어에서 변하면 신규 원본 세이브 검증 필수.
- 유씨별원: `35271_1.lua`, `seed_lsby`, 재료 가중치, `GetP(8915)` 조건과 상태 전달.
- **실제 장비 예측이 최우선**: 특수 드랍은 장비·시드·후속 호출에 영향을 미치는 범위만 반영하며, 벽유교 별도 JHRandom 재료 추첨의 세부 복구는 의존성 입증 전까지 중단.

## 실행

```bash
python mixed_gate_schedule.py \
 --save '/private/1123(입장전).json' \
 --source-root /private/v30 \
 --registry /private/gate-60-source-registry.json \
 --schedule '벽유교,창옥,연왕부,유씨별원,유씨별원,유씨별원'
```

기본 출력은 한국판 보스 이름·장비명·색상만 표시하고, `--output-private` 지정 시에만 원시 시드 데이터를 포함한 상세 결과를 로컬 파일로 보관한다. GitHub와 공개 ZIP에는 개인 세이브·시드·원본 게임 바이너리를 포함하지 않는다.
