# 출시 4관문 장비 ID·색상 대 필드/장비 옵션 RNG 경계 감사

2026-11-24 · 연구 브랜치 `research/dungeon-rng-original` 전용

## 검증 대상

- 실제 1123(입장전) → 1124 세이브 비교. 개인 원본, 난수값, 계정 식별자, 장비 객체 ID는 공개 파일에서 제외.
- 실측 순서 벽유교→창옥→연왕부→유씨별원 3회.
- `Rnds.Sds`의 출시 관문 독립 레인 9개, 필드 `aidrop*` 및 `mdrop` 22개, 장비 종류별 `Rnds.Eds` 9개, 특수몹 등장 시드, `Rnds.S`를 구분.

## 관찰

1. 실제 두 세이브 사이 관문 9레인은 각각 변경됨. 기존 원본 호출 재생기는 종료 시드 9/9를 재현.
2. `aidrop*`/`mdrop` 22레인은 변경되지 않았으나 제릉 특수몹 연관 `seed_35256`와 전역 `Rnds.S`는 변경됨. 따라서 단순히 필드 사냥이 없었다고 확정하지 않음.
3. 일반 90급 장비 ID **4009, 4209, 4409, 4609, 4809, 5009, 5209, 5409, 5609**의 `Eds`는 전부 변경됨. 현재 일반 장비 **ID·색상 재생기는 이 Eds를 업데이트하지 않는다**. 이는 장비 최초 옵션/정련·망정 시드 모델이 미완성이라는 명시적인 경계임.
4. 해당 9개 `Eds` 시작값을 바꿔도 현 관문 원본 모델의 장비 ID·색상은 동일. 필드 `aidrop*`/`mdrop` 시작값을 바꾼 경우도 동일. **이것은 코드의 입력 의존성을 검증한 것이지 실제 게임의 완전한 RNG 독립성을 입증한 결과가 아니다**.
5. 1124 신규 일반 장비 16개 중 예상한 첫 13개 ID·색상이 생성 순서까지 일치. 개인 장비 객체에는 개별 보스 로그가 없으므로 역추적 증거가 아니라 순서 기반 홀드아웃으로 명시.
6. 다른 일반 활동에서 변경된 `Sds`는 96개. 이 변화의 원인을 모두 관문 클리어에 귀속시키지 않음.

## 구현과 검사

- `gear_lane_boundary_audit.py` — 개인 세이브를 로컬에서만 읽고 원시 시드값 없이 안전한 요약 출력.
- `test_gear_lane_boundary_audit.py` — 관문 레인 9개 분리, Eds 9종 차분, 필드 22레인, 제릉 특수몹 시드 예외, 13개 장비 일치, Eds/aidrop/mdrop perturbation, 두 혼합 순서 비교의 **9개 단위검사**.
- 추가로 기존 `test_mixed_gate_schedule`, `test_launched_gate_forward`와 함께 **25개 테스트** 통과. 전체 9모드의 이전 원본 60개 TDUP/TSET 테이블/181동작 검사는 Node에서 통과하며, 미출시 모드의 코드는 수정하지 않음.
