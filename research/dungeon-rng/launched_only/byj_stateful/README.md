# 벽유교 일반 장비 2회 연속 재생 — 60014 원본 분기 보존

출시된 일반 관문 **벽유교**의 원본 `35227_1.lua` 재생기에서 원본 단계/보상 변수의 다음 회차 전달 기능만 추가한 연구 코드다. **특수재료 지급 함수의 역공학은 일반 장비 결과에 직접 영향이 확인되기 전까지 중단**한다.

- `byj_forward_source_copy.py`: 검증된 60014 `v19_byj_replay.py` 로직을 그대로 복제하고, 원본 모델 경로를 외부 입력으로 전달하며 `post_globalVariable`만 추가한 연구용 사본.
- `byj_stateful_forward.py`: `seed_byj`, `win_byj`, `roll_2922/2923/3970`, 장비 슬롯 및 색상 변수를 실제 다음 회차에 전달한다. 원본은 **장비 미드랍일 때도 색상 추첨을 시행**하므로 색상 변수 갱신을 유지한다.
- 분기 37은 `Branch.byj_bz.step < 0`, `glm_open == 0`, `win_byj >= 10` 조건. **다음 회차에서도 해당 Branch.step이 변하지 않는다는 조건부 전방 예측**이며, 정보가 누락되면 중단.
