# 낭만강호 출시 4관문 — 특수 보상 미획득 가상 상태의 실제 RNG 전방 재생

검사일 2026-11-24. 대상: 연왕부·창옥·벽유교·유씨별원. 미출시 관문 5모드 연구 동결 유지.

## 핵심 구현

- 기존 보상 지급 조건 40개, 재진입 복구 37개, 원본 재료 누적 가중치 46개와 **기존 관문 전방 RNG 재생기를 같은 실행 경로로 호출**한다.
- 별개 시나리오: ① 기존 상태 ② `get_*` 지급 카운터만 0 ③ `num_*` 재료 카운터만 0 ④ 둘 다 0 (벽유교 기존 최초 초기화 유지) ⑤ 둘 다 0 + 벽유교 원본 최초 초기화 ⑥ 유씨별원 원본 숫자 키 `8915`=1.
- 가상의 `get_*` 초기화는 실제 보유 장비·임시 스코프·과거 클리어 시드/횟수를 바꾸지 않는다. 이것을 **실제 미획득 계정**이라고 지칭하지 않는다.
- 벽유교 `35227_1.lua`의 **10~23단계 원본**: `first_rdward==0` 조건의 재료 가중치 13개 초기화, 개별 `num_*` 한도 초과한 항목 제거, `first_rdward=1` 설정. 이 준비 단계는 RNG를 사용하지 않는다. **이후 보상 재료 지급 consumer 단계(24)는 기존 벽유교 보스 RNG 재생에 포함되지 않으므로, 결과 변화가 없었다는 이유로 전체 관문 드랍이 같다고 판정하지 않는다.**
- 유씨별원 숫자 `GetP(8915)`와 `get_8915` 지급 카운터를 구분. 조건에 따라 1 RNG 호출이 사라질 수 있다.
- 개별 관문 1회 전방 결과를 시나리오별로 비교. 일반 장비 ID/한국판 이름/색상, 호출 횟수, 종료 시드 변화 및 특수 지급 가능 조건을 별도 출력.
