# 관문 드랍 원본 Lua 테이블 키 검증 (독립 연구)

실측 드랍 ID·색상은 원본 LuaJIT `pairs` 순회가 확정되기 전에는 단일 결과로 표시하지 않는다.
`typed-weight-roll.cjs`는 숫자 키 `50`, 문자 키 `"50"`, 뒤 공백이 있는 문자 키 `"50 "`를 분리한다.
삽입순서는 보존하지만 순회순서로 간주하지 않는다. 실제 네이티브 순회순서가 확인되어 별도 입력될 때만 조건부 가중치 구간을 계산한다.
가능한 순회순서가 둘 이상이면 `compareOrders`로 결과가 단일하게 수렴하는지 검사한다.

실행: `node research/dungeon-rng/typed-weight-roll.test.cjs`

연구 스코프: 60014 유씨별원·벽유교의 원본 키 타입 검증. 이 모듈은 게임 원본 LuaJIT 해시, 난수 알고리즘, 실제 장비 드랍 엔진을 복원했다고 주장하지 않는다.
공개 사이트·V82·정련·망정 기능은 변경하지 않는다.
