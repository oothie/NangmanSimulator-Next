# 한국판 60014 관문 20~80급 · 원본 LuaJIT 가중치 순회 불확실성 진단

## 기존 연구 엔진에서 식별한 핵심

보존된 7관문 연구 ZIP의 `engine/source_order_forward.cjs`와 `engine/jxz_original_forward.cjs`는 가중치 테이블 구성 시 `SourceTable.put('key')`를 먼저 호출한다. 이 문자열 메타 키가 실제 게임의 `JHTaskFile.createFromFile → getLuaJsonFile` 반환 테이블에 **존재하는지, 언제 삽입되는지**는 원본 한국판 런타임에서 독립 확인되지 않았다.

이는 작은 문제로 취급할 수 없다. LuaJIT 2.1-beta3의 소스 기반 해시 노드 모형에서는 숫자 키, 숫자처럼 보이는 문자열, 메타 키의 삽입 순서가 가중치 순회를 변경한다.

## 수행한 원본 자료 기반 분석

보존된 원본 레지스트리 `native_source_registry.json`의 **40개 가중치 테이블**에서 실제 키 타입·원본 효과 배열을 기준으로 다음 세 후보만 비교했다.

1. `key` 메타 키가 가장 먼저 삽입된 해시 모형 (기존 연구 엔진)
2. `key` 메타 키가 가장 마지막에 삽입된 해시 모형
3. `key` 메타 키가 없는 해시 모형

정적 테이블 38개는 기존 원본 파일의 타입/가중치 그대로, 취선채·추가성 동적 테이블 2개는 각 `GetP('roll_1216')`, `GetP('roll_1049')`가 **0인 합성 조건**에서 계산. 실제 사용자 세이브, 계정 식별자, 실제 시드 미사용.

| 항목 | 두 모형의 가중치 키 선택이 달라지는 횟수(총 4,000) |
| --- | ---: |
| 메타 키 먼저 vs 마지막 | 1,080 |
| 메타 키 먼저 vs 없음 | 2,455 |
| 메타 키 마지막 vs 없음 | 2,325 |

정적 38개 테이블의 **보상 효과 자체**를 비교하면 총 3,800개의 합성 추첨 중:

| 원본 보상 효과 비교 | 다르게 선택한 횟수 |
| --- | ---: |
| 메타 키 먼저 vs 마지막 | 900 |
| 메타 키 먼저 vs 없음 | 2,275 |
| 메타 키 마지막 vs 없음 | 2,325 |
| 세 모형에서 보상 효과가 모두 동일 | **1,240** |

색상이 달라지는 구간과 실제 장비 미드랍/무기/방어구 분기가 달라지는 구간을 구분했다. 예를 들어 천일교 일부 보스는 서로 다른 가중치 키가 **같은 미드랍 분기**를 실행한다.

**중요:** 이 수치는 LuaJIT 해시 순회 *후보 모형끼리의 차이*다. 한국판 게임 런타임의 실제 해시 구성·삽입 순서·RNG 소비와의 일치 여부 또는 실제 아이템 예측 정확도를 입증하는 값이 아니다.

## 신규 내부 기능

- `audit_40_table_synthetic_key.cjs`: 정적 38개에서 메타 키 선행/부재 가설 비교
- `audit_40_table_metadata_positions.cjs`: 동적 2개를 포함한 40개, 선행/후행/부재 **세 모델** 비교
- `audit_40_table_equipment_effects.cjs`: 38개 정적 테이블에서 키 선택 차이와 실제 보상 효과 차이 분리
- `gate_table_order_preflight.cjs`: 주어진 관문의 원본 경로별 가중치 추첨값에 대해 각 모델의 효과가 같은지 확인하고, 누락 경로·동적 분기는 별도 표시. 동일 효과여도 **게임 원본 미래 드랍 확정**으로 승격하지 않는다.

위 도구들은 공개 사이트 UI나 실제 관문 드랍 엔진을 임의의 세 모델 중 하나로 바꾸지 않는다.

## 계속 필요한 검증

1. 실제 원본 `getLuaJsonFile` 테이블에 메타 키 `key`가 있는지, 있다면 정적 키보다 전/후에 삽입되는지 원본 바이트코드 또는 네이티브 실행으로 확정.
2. 메타/리해시 과정을 포함한 실제 한국판 LuaJIT `pairs` 순회 확인.
3. 원본 RNG 소비/다른 조건부 특수재료 분기를 연속 연결하고 신규 세이브를 **사전 봉인 → 클리어 → 사후 확인**으로 블라인드 대조.

문향교·무신전·벽유교 본단 미출시 관문은 동결. 한국판 출시 90급 4관문과 공개 시뮬레이터·버전은 변경하지 않음. 개인 세이브·원시 난수·실제 장비 OnlyID 없음.
