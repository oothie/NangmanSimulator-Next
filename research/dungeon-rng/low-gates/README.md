## 참조 모델 일치 검사
현재 확보된 낮은 급수의 일반 드랍은 취선채(3명), 추가보(3명), 혈의루(3명), 철인문(3명), 천일교(4명), 고골문(3명): **19보스**.
일반 장비 후보와 무기 후보, 원본처럼 보이는 outer/color 가중치, 시드 키, 보상 종류를 산부진 추출본에서 보존.
보스의 유일 장비 참조 기록 **15개** 중 `dungeon-orange.js`의 조건부 재생 route와 연결된 항목은 **11개**, 나머지 **4개는 전용 재생 route 미확보**다. 참조 모델 자체의 장비·특수 보상 데이터 일치 검사는 19/19보스, 15/15기록 통과. 이 수치는 실제 원본 RNG 전방 예측 성공률이 아니다.

별도 `orange-` 보상만 기록된 묵문유적은 일반 장비 드랍 함수 확인 전이므로 일반 장비 테이블을 임의 생성하지 않는다.
초기 관문은 중국판 공개 자료에서 20급 취선채부터 안내된다. 요청한 **10급 구간은 관문 자체의 존재 여부를 포함해 미확인**이며, 40급 묵문유적은 일반 장비 소비자 함수가, 50급은 별도 관문 유무가 현재 확보된 원본에서 확인되지 않았다. 일반적인 게임 가이드의 등급표는 원본 지급 함수 증거와 구별한다.

## 미복구 / 검증 불가
1. 10급부터 고골문까지 실제 60014 LuaJIT/SBv3 `AddBattleDrop` 소비자 및 1차 특수 지급자 명령.
2. `JHRandData.weightRand` 호출 직전 조건·숫자/문자 키 `TDUP/TSET`·실제 `pairs()` 순회.
3. 스토리 스테이지, 미획득/획득 완료 보상 상태가 선행 RNG에 미치는 영향.
4. 세이브 전후 종료 시드·실제 장비·색상·특수 드랍의 독립 전방 재현.

**현재 검증의 의미:** 19보스·15개 특수 보상 기록이 확보된 참조 모델에 일치하는지 검사한다. 원본 함수를 완전 복원했거나 게임 실측을 재현했다고 주장하지 않는다.
