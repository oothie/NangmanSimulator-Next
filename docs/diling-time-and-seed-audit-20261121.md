# 제릉 필드 사냥 — 시간 변수 및 90레벨 드랍 시드 점검 (2026-11-21)

## 실제 확인된 결과 — 2026-11-21 사용자 정정 반영

- `1121.json` 기준 제릉 일반 필드 사냥 **9회차** 수라장갑(4009) **백색** 획득. 처음 전달된 10회차는 이후 사용자가 9회차로 정정함.
- 원본 소스 랩 v29는 `35255 조우 → walk_event_tomb_outrim → 조건부 35256` 경로를 분석했으나, **전체 일반 필드 사냥 1회 = 이 이벤트 호출 1회**라는 근거는 확보하지 못함.
- 실제 1121 상태: `Rnds.Sds.rollenemy_tomb=1456365169`, `Rnds.Sds.seed_35256=492075794`, `globalVariable.eat_2659=9`, `globalVariable.rollenemy_tomb2=200`. `globalVariable['3007']`은 없음.
- 현재 소스 기반 이벤트 호출 모델의 **9번째 호출**은 `roll=825`, `825 - (9×10)=735`, 비교 기준 `rollenemy_tomb2=400`이므로 **특수몹 미등장**. 10번째 이벤트 호출은 특수몹 등장으로 계산됨. 이는 **실제 사냥 9회차** 결과와 불일치함.
- 보상 3! × 색상 4! = **144개** 순열 모두 9번째 이벤트 호출에 장비 드랍을 만들 수 없음. 보상 분기를 조정하여 문제를 해결할 수 없으며, 사냥 번호와 이벤트 호출 번호의 연결을 확인해야 함.
- 이전 10회차 관측으로 계산한 24개 후보 및 50회 사냥 결과는 **폐기**.
- 그 밖의 초기 진입 호출, 전투 선별 이벤트, 추가 시드 소비 등은 원본 클라이언트의 실제 호출 경로로 검증되지 않았음. 원본 소스 없이 임의 offset을 넣지 않음.

## 산부진 원본 기반 시각 조건의 범위

### `vendor/sanbujin/drops/wild-core.js`

1. `loot`가 먼저 **세이브의 필드/특수몹 난수 시드**로 보상 ID 및 색상을 고름.
2. 장비 추가 옵션은 `equipmentSeed(state, cfg, id, unix, persistent)`에서 별도의 초기 난수를 얻음.
3. `persistent = target.kind === 'story'`: **새북·십방집 등의 특수몹 보상 함수**. 90급 일반 장비는 `Rnds.Eds[itemId]`를 읽고 `draw(seed, 99999999)`로 한 단계 진행하여 옵션 초기 난수를 구함. 사냥 날짜/시각을 전달하지 않음.
4. `persistent = false`: 일부 저레벨 일반 `aidrop` 장비. 옵션 초기 난수를 `output(raw(BigInt(unix))) % 2047483645 + 1`로 계산. **입력한 중국 표준시(UTC+08:00)의 초 단위 시각**이 옵션에 영향을 줄 수 있음.
5. 두 가지 모두 시간 입력은 보상 ID/품질 판정 후에 사용되므로 **시간 변경으로 아이템 ID·색상이 바뀌지 않음**.

### `vendor/sanbujin/drops/tomb-core.js`

- 일반 필드 NPC 35255의 특수몹 발생 판정: 저장된 `Rnds.Sds.rollenemy_tomb` 및 `eat_2659`, `rollenemy_tomb2` 진행 변수.
- 특수몹 NPC 35256 보상/품질/장비 ID 가설: 저장된 `Rnds.Sds.seed_35256`. 보상 분기 배열 순서는 원본 LuaJIT 테이블 순서가 복구되지 않아 **아직 미검증**.
- 90레벨 장비 생성 시 일반 필드/관문과 공유하는 `Rnds.Eds[itemId]`를 한 단계 진행하도록 추적. **이 추적은 최종 정련·망정 수치 예측이 아니며**, 제릉 분기 모형 검증을 대신하지 않음.
- 현재 모델에서 실측 시각은 제릉 출현/ID/색상 판정 입력 변수가 아님. 이를 근거 없이 보정값으로 사용하지 않음.

## 후보 순서 계산과 단위 주의

- 보상 분기 3! × 색상 분기 4! = 144개는 **보상 분기 순서**만 바꾼 계산임.
- 실측한 **9회차** 장비는 현재 제릉 `35255` **이벤트 호출 9번** 결과와 맞지 않으며 후보 0개.
- 이벤트 호출 50회 기준 35256 특수몹 등장 17회라는 값은 계산할 수 있지만, 이를 **제릉 일반 필드 사냥 50회**의 실제 출현 횟수로 보고해서는 안 됨.
- (루트 호출 관계, `3007` 누락, 제릉 35255 선택/소환 단계, 장비 보상 분기 LuaJIT 순서) 모두 확인 전으로 둔다.
