# 제릉 필드 사냥 — 시간 변수 및 90레벨 드랍 시드 점검 (2026-11-21)

## 실제 확인된 결과 — 2026-11-21 최종 정정

- 사용자 실측 **일반 사냥 8번째**, 적 이름 **거령 병용**, **수라장갑(4009) 백색** 획득. 기존 10회차 및 9회차 주장은 모두 사용자가 정정하였으므로 폐기.
- 거령 병용에게서 **경험치 11,000과 12,000 모두** 확인. 경험치 12,000만으로 내부 특수몹을 구분하는 규칙은 미확인.
- 거령 병용 처치에서 **100레벨 재료 양신지** 획득 확인. 양신지 드랍만으로 내부 NPC 35256을 확정할 수 없음.
- 원본 분석은 `35255 조우 → walk_event_tomb_outrim → 조건부 35256` 경로. 실제 일반 전투 1회가 이벤트를 반드시 1회 소비하는지 **미검증**.
- `1121.json` RNG: `rollenemy_tomb=1456365169`, `seed_35256=492075794`, `eat_2659=9`, `rollenemy_tomb2=200`. `globalVariable['3007']`은 저장되지 않음.
- 이 입력으로 35255 이벤트를 8번 호출했다고 가정하면 **8번 호출은 특수 경로 등장**(`roll=538`, `538−90=448 ≤ 기준 600`). 144개 보상·색상 순서 중 **12개가 8번 호출에서 4009 백색**을 생성.
- 따라서 기존 9번 호출 미등장과 실제 9회차의 불일치 판정은 더 이상 유효하지 않음. 단, **8번째 실제 사냥=8번째 35255 호출은 여전히 가설**.
- 관측값과 맞는 12개 후보도 원본 `pairs()` 순서를 검증한 것이 아님. 무근거 시드 시프트·시간 보정 불허.

## 산부진 원본 기반 시각 조건의 범위

### `vendor/sanbujin/drops/wild-core.js`

1. `loot`가 먼저 **세이브의 필드/특수몹 난수 시드**로 보상 ID 및 색상을 고름.
2. 장비 추가 옵션은 `equipmentSeed(state, cfg, id, unix, persistent)`에서 별도의 초기 난수를 얻음.
3. `persistent = target.kind === 'story'`: **새북·십방집 등의 특수몹 보상 함수**. 90급 일반 장비는 `Rnds.Eds[itemId]`를 읽고 `draw(seed, 99999999)`로 한 단계 진행하여 옵션 초기 난수를 구함. 사냥 날짜/시각을 전달하지 않음.
4. `persistent = false`: 일부 저레벨 일반 `aidrop` 장비. 옵션 초기 난수를 `output(raw(BigInt(unix))) % 2047483645 + 1`로 계산. **입력한 중국 표준시(UTC+08:00)의 초 단위 시각**이 옵션에 영향을 줄 수 있음.
5. 두 가지 모두 시간 입력은 보상 ID/품질 판정 후에 사용되므로 **시간 변경으로 아이템 ID·색상이 바뀌지 않음**.

### `vendor/sanbujin/drops/tomb-core.js`

- 일반 필드 NPC 35255의 특수몹 발생 판정: 저장된 `Rnds.Sds.rollenemy_tomb` 및 `eat_2659`, `rollenemy_tomb2` 진행 변수.
- 특수몹 NPC 35256 보상/품질/장비 ID 가설: 저장된 `Rnds.Sds.seed_35256`. 보상 분기 배열 순서는 원본 LuaJIT 테이블 순서가 복구되지 않아 **아직 미검증**.
- 90레벨 장비 생성 시 일반 필드/관문과 공유하는 `Rnds.Eds[itemId]`를 한 단계 진행하도록 추적. **이 추적은 최종 정련·망정 수치 예측이 아니며**, 제릉 분기 모형 검증을 대신하지 않음.
- 현재 모델에서 실측 시각은 제릉 출현/ID/색상 판정 입력 변수가 아님. 이를 근거 없이 보정값으로 사용하지 않음.

## 후보 순서와 단위 주의

- 보상 3! × 색상 4! = 144개는 `seed_35256` 분기의 순열 후보이며 실제 LuaJIT 순서를 확정한 값은 아님.
- **8회차 수라장갑 백색**은 내부 **8번째 이벤트 호출**과 대응한다고 가정할 때 144개 중 12개 후보가 일치함. 실제 사냥과 이벤트 호출 연결은 여전히 검증 전.
- 동일 거령 병용에게서 경험치 **11,000/12,000** 모두 나오므로 경험치는 별도 추적하고 특수몹 판정식에 사용하지 않음.
- 제릉 이벤트 호출 50회에서 35256 등장 17회라는 모델 출력은 실제 일반 사냥 50회 예측이 아님.
- `3007` 누락, NPC 화면 이름↔내부 ID 매핑, 거령 병용에서 장비가 떨어지는 조건, Lua 보상 순서는 후속 검증 과제로 유지.
