# 제릉 일반 필드 사냥 실측 기록 · 2026-11-21

## 사용자가 직접 관측한 사실

- 제릉 일반 필드에서 **파진 병용**과 **거령 병용**을 확인함.
- 사용자는 파진 병용이 일반몹, 거령 병용이 특수몹일 가능성을 관찰 중임. **거령 병용에게서 90레벨 장비 수라장갑 백색이 드랍된 것까지 실측 확인**. 단, 내부 NPC 35255/35256과 화면 이름의 정확한 매핑은 아직 미확정.
- 전투 보상 경험치는 **11,000**인 경우와 **12,000**인 경우가 있음.
- **거령 병용** 처치 시 경험치 **11,000과 12,000을 모두 직접 확인**함. 따라서 **12,000 경험치만으로 특수몹을 판정하는 규칙은 성립하지 않음**.
- **거령 병용 처치에서 100레벨 재료 '양신지' 드랍 확인**. 단, 양신지는 제릉 일반 필드 100레벨 몹의 드랍 재료로 공개 공략에서도 확인되며, 이것만으로 35256 특수몹이라고 확정할 수 없음.
- **최종 정정 실측**: `1121.json` 사냥 전 기준 **일반 사냥 8번째**, 화면상 적 **거령 병용**, **수라장갑(4009) 백색** 드랍. 사용자가 기존 10회차 → 9회차 → **8회차가 정확하다**고 정정했으므로 9·10회차 주장은 폐기.

## 기존 60014 소스랩과 분리할 점

- 원본 분석에는 NPC **35255 조우 트리거 → walk_event_tomb_outrim → 조건부 NPC 35256** 보상 경로가 기재되어 있음. **파진 병용**·**거령 병용**의 화면 표시 이름과 이 내부 NPC ID를 직접 연결할 증거는 아직 없음.
- 경험치 11,000/12,000, 특정 적 외형/이름, 양신지 드랍 여부와 `Rnds.Sds.rollenemy_tomb`의 특수 트리거는 현재 각각 **독립된 관측값**으로만 기록함.
- 양신지 같은 100레벨 재료 드랍과 90레벨 장비 ID/색상 판정은 다른 보상 후보일 수 있음. 한 전투에서 재료가 나왔다고 장비 시드가 반드시 진행했다고 취급하지 않음.
- 35255 **이벤트 호출 횟수**와 사용자가 세는 **일반 필드 사냥 횟수**를 동일하게 취급하지 않음.

## 아직 검증되지 않은 가설

1. 파진 병용 = 일반 경로, 거령 병용 = 조건부 35256 특수 경로.
2. 12,000 경험치 = 특수몹 등장. **거령 병용이 두 경험치를 모두 지급해 단독 판별 기준으로 사용할 수 없음**.
3. 양신지 드랍 = 특수몹만의 보상.
4. 35255 이벤트 호출 1번 = 일반 전투 1회.

위 사항은 사용자 실측 또는 원본 함수/리소스의 직접 매핑 전까지 드랍 예측 조건으로 사용하지 않음.

- 중국 BWIKI 养神芝: 제릉 외전의 100레벨 필드 몬스터에서 확률 드랍.

## 8회차 실측과 현재 모형의 관계

- `1121.json`에서 계산되는 내부 35255 **8번째 조건부 이벤트 호출**: `rollenemy_tomb` 판정 538, 보정값 448, 기준 600이므로 특수 경로 **등장**.
- 3! 보상 분기 × 4! 색상 분기 = 144개 후보 중 **12개가 호출 8번에서 수라장갑(4009) 백색을 재현**. 이 조건으로 남는 보상 순서는 `other → equipment → none`이고 색상 순서는 여전히 12개 후보.
- 이는 단일 실측과 내부 **호출 번호를 동일하다고 가정했을 때의 조건부 적중**일 뿐, 실제 필드 8회차와 내부 이벤트 호출 8번의 대응 증거는 아님.
- 사용자가 보고한 경험치 11,000과 12,000은 동일 이름 거령 병용에서 모두 나왔으므로, 등장 시드 분기나 장비 ID·색상 계산에 넣지 않음.
